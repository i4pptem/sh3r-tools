# Development

## Prerequisites

- Windows x64; Node.js 24+; pnpm **11.25.0**.
- Optional Blender 4.2+ for FBX and morph-workspace integration (tested: 5.2.2).
- Optional pinned FFmpeg runtime for movie/media conversion. It is downloaded separately and ignored by Git.
- No game assets are required for the synthetic Node test suite. Your own game installation is needed for real-asset and in-game validation.

```powershell
pnpm install --frozen-lockfile
pnpm setup:electron
pnpm test
pnpm check:repo
pnpm build
pnpm start
```

The workspace explicitly permits esbuild's install script. Electron 44 uses an explicit runtime installation step, provided by `pnpm setup:electron`; packaging can also acquire its pinned runtime independently. `app/ui/bundle.js` is generated by the build and is not committed. All application and package versions are pinned in `package.json` and `pnpm-lock.yaml`.

For local media workflows:

```powershell
pnpm setup:media
# Or reuse the exact verified upstream archive:
pnpm setup:media --archive "D:\Downloads\ffmpeg-n8.1.3-win64-lgpl-shared-8.1.zip"
```

The installer verifies the archive and the extracted file manifest. It refuses to replace an existing mismatched runtime. See [media provenance](../tools/media/README.md).

## Source layout

| Location | Responsibility |
| --- | --- |
| `app/main.cjs`, `app/preload.cjs`, `app/worker.mjs` | Desktop lifecycle, IPC and asset-work execution |
| `app/ui/` | Viewers, editor controls, styles and original branding |
| `core/` | Native parsers/writers, project/build logic and authenticated runtime patch generation |
| `tools/blender/` | Model/animation/cutscene exchange bridges, Blender Morph Tools and Blender regression scripts |
| `tools/native/` | Font/model/world runtime sources, DLL/ASI asset loader, profile generators and native test hosts |
| `tools/media/` | Verified optional media installer, manifest and notices |
| `tests/` | Synthetic, self-contained regression suite, including native layout validation |
| `docs/` | User workflows, patch behavior, validation and release instructions |

Archive source files are immutable inputs. Edits become staged payloads; Build mod writes a separate output. Keep parser/writer validation at the format boundary. Test meaningful native layout and round-trip invariants, not merely the same algorithm copied into an assertion.

## Native font uploader

The ordinary application build uses the committed, validated `core/font-runtime-profile.json`; MSVC and Python are **not** required for it. To rebuild the original C uploader, use an **x86 MSVC developer shell**, Python 3 and `pefile`:

```powershell
python -m pip install pefile
powershell -NoProfile -ExecutionPolicy Bypass -File tools/native/build-font.ps1
```

The script compiles an import-free x86 DLL and extracts a candidate profile into `build/native/font-runtime-profile.json`. The compiler used for the shipped profile was MSVC 14.51.36231. Linker/compiler metadata can vary, so byte identity is not promised across toolchains. Do not replace the committed profile until its relocations, entry point and runtime behavior have been independently validated. This script builds code; it does not patch or start the game.

## Blender checks

These checks use Blender's bundled Python and synthetic geometry; no game assets are required. In PowerShell, replace `blender` with your executable path if it is not on PATH:

```powershell
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/test_morph_transfer.py
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/test_morph_landmarks.py
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/test_morph_regions.py
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/blender/test_morph_workflow.py
```

The portable package copies the current `tools/blender/sh3_morph_transfer.py`. In 1.0.0 its add-on version is **1.3.2**. The Inspector's **Get Blender morph add-on…** action exports that bundled file; no separate download or Blender auto-install is performed.

## Packaging

```powershell
pnpm package
pnpm release:zip
```

The first command builds the UI and packages Electron with production dependencies, source modules, bridge scripts and documentation. It deliberately excludes local media binaries, game files, research, exports and user projects. The portable folder includes **Install media.cmd**, using Electron's embedded Node runtime to install the optional media component without a system Node installation.

The ZIP script verifies archive entries against the packaged files and writes SHA-256 checksums. It refuses to overwrite existing release ZIPs. The source ZIP contains the public source tree and lockfile, not `node_modules`, binary runtime downloads or generated output. See [Releasing](RELEASING.md).

The GitHub workflow runs source checks, synthetic tests and the UI build on Windows. It has read-only repository permissions and does not publish a release. Game/Blender/live-runtime checks remain separate from CI; [Validation](VALIDATION.md) records their scope.
