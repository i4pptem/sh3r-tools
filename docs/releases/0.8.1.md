# Silent Hill 3 Tools 0.8.1

Hotfix for character models with larger embedded textures and for replacement mesh/material mapping. Developed by **i4pptem**.

## What changed

- **Large character models can start in the game.** Build mod now calculates the effective model, animation, shadow and cache reservations from the complete game data folder. When a staged asset exceeds the stock 40 MiB character-file arena, it generates a matching **sh3.exe** with a separate 128 MiB character arena. This fixes the observed startup crash with three 2048×2048 BGRA textures embedded in Heather's MDL.
- **Model replacement exposes the original visibility settings.** Choose each part's gameplay/cutscene/equipment template and texture slot independently. The dialog warns when skin weights refer to bones from incompatible original variants, a cause of stretched geometry that can be absent from the preview.
- **Rebuilt primary parts are grouped by texture.** This keeps the game's fixed material-run table within its native bounds while preserving the selected visibility and render settings.
- Existing recognized morph, INDEX32, secondary mesh, picture and font executable patches remain composable with the new character patch.

## Install and use

Extract **Silent-Hill-3-Tools-0.8.1-win-x64.zip** completely, then run **Silent Hill 3 Tools.exe**. Open the game's **data** folder. If **Build mod** emits **sh3.exe**, install it together with the generated data after closing the game and backing up the replaced files. The application archive contains no game executable, archives or copyrighted game assets.

GLB images are not imported automatically during a model rebuild. Assign the native texture slots in the replacement dialog and import the corresponding PNGs. Keeping an original morph mesh also keeps its UVs, so its image must still match those coordinates. The tool warns about bone/visibility mismatches; it cannot automatically author correct gameplay, cutscene, facial-expression or weapon-grip variants for an unrelated replacement model.

Windows x64; no Node.js installation is needed. **Install media.cmd** supplies optional verified FFmpeg media support (internet required). Blender 4.2+ is needed for FBX and morph workspaces. The source archive is **Silent-Hill-3-Tools-0.8.1-source.zip**; SHA-256 values are in **SHA256SUMS.txt**. Source license: **GPL-3.0-only**.
