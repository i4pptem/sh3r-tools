# Silent Hill 3 Tools 1.0.1

**More animations to explore, faster asset replacement, and fixes for sound and modded models.**

## Actions for more characters

Browse enemy ANM banks by individual **Actions**, including Memory of Alessa, with native frame ranges, loop settings and playback rates. Compatible Heather costumes share her gameplay Actions; reflection models now accept the same banks after skeleton verification. Separate **Game Over** ranges are available for Heather and Split Worm.

The bank selector shows Action counts and puts verified banks first. Open **Animation → Clips & tools**, choose a bank, then select **Action range**. The app reads the supported `sh3.exe` beside the data folder without modifying it. Unverified banks retain manual range selection.

## Replace textures and sounds by folder

Use **Replace from folder…** in Asset Library, Texture Inspector or an archive's context menu to prepare multiple replacements together:

- PNG textures in supported standalone assets, models, maps and original-size font atlases.
- Native WAV/ADX/AIX files, numbered AFS entries, and WAV tracks for AIX/HD+BD through the existing converters.
- Archive-aware matching with clear ready, unchanged, ambiguous and invalid results.
- Selectable replacements, visible progress and atomic staging: a failed batch cannot leave half the selection applied.

Choose a folder → review the matches → **Stage selected** → **Build mod**. Texture Fit / Full size restrictions and native audio limits still apply. See the [naming examples and supported formats](https://github.com/i4pptem/sh3r-tools/blob/main/docs/BATCH-REPLACE.md).

## Fixes that make a difference

- **Silent audio replacements:** corrected AFS sector layout and overlay reads so changed samples play through the native game audio system. The menu WAV reported in [issue #2](https://github.com/i4pptem/sh3r-tools/issues/2) was confirmed audible in game.
- **Zero skin weights:** valid third-party models now open correctly. SH3 stores three weights and calculates a fourth; the reader preserves that native influence, including collapsed parts used to hide old geometry. Preview and GLB export retain it. New-topology rebuilding keeps its existing three-influence authoring limit.
- **Remembered folders:** file dialogs retain confirmed locations after restarting. Open data folder has its own history, related import/export operations share locations, and cancellation does not erase them.

## Installation

Extract the entire **Silent-Hill-3-Tools-1.0.1-win-x64.zip** into a new folder and run **Silent Hill 3 Tools.exe**. Keep all included files together. Blender 4.2+ is needed for FBX/.blend exchange; **Blender Morph Tools 1.3.2** remains bundled. Optional audio/video conversion tools can be installed with **Install media.cmd**.

**Updating an audio mod:** rebuild AFS mods made with 1.0.0, then install the complete generated output. The updated overlay DLL and version-2 asset index must come from the same build; replacing only one is insufficient. Back up installed mod files first.

## Validation and current limits

**394 automated tests passed**, alongside real model/archive checks, native archive-reader and Action-table checks, and application UI checks. All 28 MDLs in the reported modder archive now parse; an unchanged textured GLB round trip preserves the supplied standalone MDL byte-for-byte. These checks do not replace in-game testing of authored mods. [Validation details](https://github.com/i4pptem/sh3r-tools/blob/main/docs/VALIDATION.md).

Reported antivirus detections on the runtime DLL/ASI remain under investigation. Native components match independent source rebuilds, but vendor classification is unresolved; **this update is not an antivirus fix**.
