# Silent Hill 3 Tools 0.8.0

The first public preview of a unified Windows asset workspace for **Silent Hill 3 PC**, developed by **i4pptem**.

## Highlights

- ARC/AFS library with automatic movie, picture and sound discovery; selected/all archive export.
- Textured model preview, skeletal/facial playback, **GLB and FBX model export**.
- New-topology model replacement and native pose-morph rebuilding; Blender subdivision workspace.
- Experimental ANM range exchange through FBX.
- Textured MAP part editor with gizmo, multi-selection, undo, texture replacement and individual GLB exchange.
- PNG texture exchange, optional full-size pictures, 2×/4× fonts, MES/JSON, audio and FMV workflows.
- Conditional executable extensions generated from your own supported game executable when staged assets require them.
- Refreshed charcoal/copper interface, collapsible panels and focus mode.

## Download and run

Extract **Silent-Hill-3-Tools-0.8.0-win-x64.zip** completely and run **Silent Hill 3 Tools.exe**. Windows x64; no Node.js required. Run **Install media.cmd** once for optional FFmpeg media conversion (internet required). Install Blender 4.2+ separately for FBX and `.blend` workflows; 5.2.2 was tested.

Choose **Open data folder** and select the game's `data` directory. Stage edits, save a project, and use **Build mod** for separate output. Back up game files before installing replacements. If Build mod generates `sh3.exe`, install it together with its data output. No game executable or game archives are included in this release.

The source archive is **Silent-Hill-3-Tools-0.8.0-source.zip**; checksums are in **SHA256SUMS.txt**. Source license: **GPL-3.0-only**.

## Read before editing

Native rebuilding and runtime extensions are experimental and have selected, not universal, game validation. Model replacement retains the original rig. The map editor is not a complete level scripting system. Authored ANM replacements and additional MAP cases need further game testing.
