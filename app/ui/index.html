Format support
Inspect, edit and stage supported assets in their original game formats.
READY
ARC / AFS archives
Export one archive or all opened sources as native files or common formats. Browse, replace and build verified copies with the original file IDs.
EXPERIMENTAL
Model and morph rebuilding
Export models as GLB, textured FBX or a Blender scene with rig and shape keys. Export a Blender workspace with separate base/pose meshes for synchronized subdivision, or replace topology from a GLB using the original rig. Map new shape keys to native morph slots. Three influences per vertex; skinned templates only. In-game validation remains.
READY
Textures and fonts
Texture Inspector gathers supported standalone, MDL, MAP and font images in one searchable catalog. Zoom and pan; PNG fitting and palette conversion. Experimental full-size PNG import rebuilds direct-color storage for game testing. Picture alpha, palette variants and PIC. Font BIN exchange preserves glyph IDs and widths.
PLAYBACK READY
Animation
ANM skeletal and AFS / PACK facial tracks share a timeline. Preview FPS is adjustable. KG1 / KG2 contain shadow geometry. Export an ANM range to Blender or FBX; import FBX or Blender scenes with evaluated IK/FK, extra control bones and explicit cross-bank ranges. Unsupported channels are reported. Scale animation is ignored. Bank length, new channels and game event tables remain unsupported. Requires installed Blender.
LIMITED
Messages
MES text and controls with structured JSON exchange. Edit segment text; unknown Asian glyph codes remain explicit.
INSPECTION
World files
MAP editor: Ctrl/Shift-select parts, move them together, edit UVs/materials, replace one GLB mesh with new topology, and undo with Ctrl+Z. Static parts retain their visibility bounds. CLD, CAM, DED and SDB support inspection.
READY
Audio banks
Unnamed demo AFS entries are detected as ADX/WAV audio or PACK motion. ADX/WAV playback and WAV export; HD/BD and AIX retain sample import.
READY
Movie folder
Play encrypted .000 FMVs, export MPEG / WebM and re-encode edited video to the original game profile. Keep the original duration and both audio/video streams.
File-level round trips are verified. Modified assets still need scene testing in the game. No .sbd sample was available; the installed game uses .sdb.
